第一次使用？查看连接步骤
  1. 在 Google Cloud 创建或选择自己的项目，并启用 Google Drive API。
  2. 配置 OAuth 同意页面与自己的测试账号，再创建“网页应用”客户端。
  3. 将当前页面的来源网址加入授权 JavaScript 来源，回到这里粘贴客户端 ID。
  4. 保存后点“连接 Google Drive”，在 Google 页面确认实际权限。测试模式与授权期限以 Google 页面为准。
